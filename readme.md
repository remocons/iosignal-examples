## vanilla-chat No-Bundler

 번들러 도구 없이 라이브러리 공개용 CDN 서버에서 브라우저용 client IO 를 로딩하고 , iosignal 브로커 서버도 공개 서버를 사용하는 사례입니다.

- 공개된 CDN 서버에서 로딩
- importmap 설정으로  import path와 CDN 주소 대응시켜줌
